## 1. 视觉母版

先写一份全项目唯一的中文视觉母版，并为其设置稳定 `style_id`。所有角色提示词必须逐字复用以下两段：

- `shared_style_prefix`：媒介、渲染、造型比例、材质、色彩、灯光、背景和参考板总体样式。
- `shared_negative_prompt`：禁止写实漂移、二次元漂移、塑料皮肤、不同画风、年龄漂移、服装漂移、多个人、重复肢体、裁切和不可读乱码等。

角色之间只能替换“身份模块”。不得为反派、老人、侍女或群众另起画风。角色身份差异由轮廓、五官、年龄、体型、服装和道具表达。

## 2. 固定版式

使用横向 16:9、干净浅灰或暖灰背景、均匀柔和棚拍光。推荐布局：

- 左侧约 42%：最大尺寸的 3/4 全身主视图；
- 中间约 33%：正面、侧面、背面三张等比例全身图，脚底线对齐；
- 右侧约 25%：2×2 面部特写网格；
- 右下角或底部窄条：眼睛、发型/头饰、服装纹理、标志性道具、5 色以内色板；
- 标注只使用简短中文，例如“正面”“侧面”“背面”“表情”“服装细节”“道具”。

画面是角色生产参考板，不是海报、剧情插画或人物合集。所有视图之间留出明确间距，不使用装饰性边框，不让图像互相遮挡。

## 3. 人物身份锁定

人物身份模块按固定顺序写：

1. 姓名、年龄感、性别表达和角色身份；
2. 身高感、体型、肩胯比例和轮廓；
3. 脸型、肤色、眉眼鼻唇、耳朵和独特面部特征；
4. 发际线、发型、发色、头饰；
5. 服装层次、剪裁、颜色、材质、纹样、鞋履；
6. 标志性道具及惯用手；
7. 中性站姿和表演能量；
8. 不可改变项。

明确写出：“板内全部视图是同一个角色，不是不同人物；所有角度共享完全一致的脸型、五官间距、年龄、发际线、体型、服装结构、配色和道具。”

表情特写只改变肌肉和情绪，不改变骨相、妆容、发型或年龄。侧面必须显示真实鼻梁、下颌、后脑和发髻结构，不用镜像正面冒充侧面。

## 4. 中文提示词结构

`characters[].description` 使用以下顺序写成一个完整中文提示词：

```text
[逐字复用的统一风格前缀]。
制作“角色名”的专业角色参考设定板，横向16:9，一张图内包含……[固定版式]。
角色身份：[身份模块]。
一致性要求：板内全部视图是同一个角色……
标注要求：仅保留简短中文栏目名……
禁止：[逐字复用的统一负面提示词]。
```

不要输出提示词标题、Markdown 列表、参数命令或解释性前言。提示词本体必须能直接送进 ComfyUI。

## 5. Z-Image-Turbo 适配

Z-Image-Turbo 使用清晰的自然语言和明确空间关系：

- 把“同一角色”“固定版式”“每个区域放什么”写在提示词前半段；
- 使用“左侧、中央、右侧、右下角”等确定布局，不写互相冲突的构图描述；
- 身份特征具体但不过度堆砌同义形容词；
- 文字仅要求短栏目名，不要求大段人物说明，以降低乱码风险；
- 将最关键的不可改变项重复一次即可；
- 不添加采样器、步数、CFG 等未经工作流确认的参数。

`reference_sheet.z_image_prompt` 保存这一版本。当 `generation_settings.image_workflow` 为 `Z-Image-Turbo` 时，`description` 必须与该字段完全相同。

## 6. Krea2 Turbo 适配

Krea2 Turbo 使用一段连贯、视觉优先的中文描述：

- 第一语句先锁定统一媒介、渲染和角色设定板类型；
- 用连续语句描述画面分区、人物身份、材质、光线和细节；
- 避免关键词堆砌、权重括号和互相排斥的风格名；
- 强调干净轮廓、材质可读性、棚拍光和统一背景；
- 保持短中文栏目名，复杂说明放在 JSON 元数据而不是画面文字里。

`reference_sheet.krea_prompt` 保存这一版本。当 `generation_settings.image_workflow` 为 `Krea2 Turbo` 时，`description` 必须与该字段完全相同。

## 7. 质量检查

每个角色板在交付前必须全部通过：

- 与其他角色共享完全相同的 `style_id`、风格前缀、负面提示词、背景、灯光和布局；
- 有 3/4 主视图、正面、侧面、背面、四个表情特写和四类细节；
- 所有视图明确为同一人，服装和配色没有备选方案；
- 角色为完整全身，脚、头饰和道具未被裁切；
- 没有环境叙事、其他人物、群像、动作戏或海报排版；
- 提示词正文为中文；
- `description` 与当前图片工作流对应；
- 角色板生成并人工确认前，不进入分镜首帧或视频生成。
